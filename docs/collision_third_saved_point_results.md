# E51｜預測到第三個保存點

沿用 E50 的 168 組初態，以相同決策時刻 \(t=1.54\) 預測至第三個保存點 \(t=1.75\)，兩個政策都追到 \(t=5.00\)。E51 在首接觸後先用好粒子的總機械能判斷是否可能越線。靜止彈性牆與耗散阻尼下，\(K+gz\) 不增加，且地形 loss 不超過粒子高度，因此 \(z+K/g\) 是 loss 上界。本批地形高度比例為 1。其餘案例依實際接觸求自然反射，按既有時鐘施阻尼，兩次接觸之間共用一次路徑查詢。至多跟到第三次自然反射，若同窗內出現第四次即截斷。試驗中沒有到達該截斷條件。[預定協議](superpowers/specs/2026-11-15-third-saved-point-design.md)

## E50 剩下的 37 組
