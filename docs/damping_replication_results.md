# 減速分支的十種子重複驗證

完成 **50 次 NanoGPT 訓練、10 個新種子、193 個測試**。這輪沒有重現上一輪三個種子的微小平均收益：**依狀態減速目前沒有穩定優於原版 Momentum，也沒有優於固定時刻減速。** AdamW 在十個配對中都優於原版 Momentum。

## 固定的比較方式

正式種子為 **400–409**，與前輪初始化／訓練種子不同。模型與任務沿用本機官方 NanoGPT：2 層、2 頭、寬度 64、context 64、batch 8、dropout 0，共 108,352 參數；CPU float32。每組都是 **400 次真實更新、1,200 訓練前向等價單位**，沒有額外診斷或預演模型查詢，最後各評估同樣 32 個 test batch。

Momentum 的係數仍是 0.9、學習率 0.3，AdamW 學習率 0.001，weight decay 都是零。設定沿用先前調參，沒有對這輪種子重新搜尋。每個種子的五個方法以固定隨機排列執行，以減少固定順序的計時偏差。

五組分別是：原版 Momentum、原判準觸發的重置、原判準觸發的減速、固定時刻減速，以及 AdamW。原判準／門檻沒有改動：動量與梯度持續衝突、繼承速度夠大且相對位移夠大時才介入。**沒有任何加能分支。**

固定組在完成第 **80、160、240、320** 次更新後，把繼承動量乘 0.5，再繼續更新；只在四個時刻操作動量，不計算逐步狀態診斷。它提供一個簡單的、與當前狀態無關的對照。它不是介入次數完全匹配的因果實驗，因為依狀態減速的實際次數可以不同。

本輪是新種子的重複驗證，**不是未接觸的新資料集**。前輪結果已用來選擇研究方向；共同 test split 不應被描述成整個研究過程從未使用的資料。

## 結果

loss 越低越好；± 為十個種子的樣本標準差。

|---|---:|---:|---:|
| Momentum | 2.54697 ± 0.02279 | 0 | 0 |
| ＋依狀態重置 | 2.55474 ± 0.02643 | 40 | 2–6 |
| ＋依狀態減速 | 2.54824 ± 0.01083 | 46 | 2–7 |

| AdamW | **2.49770 ± 0.01264** | 0 | 0 |

依狀態減速的平均 loss 比原版高 **0.00127**，比固定減速高 **0.00142**。相對這兩個對照，都是 **5 個改善、5 個惡化**。較小的種子間 SD 是描述性觀察，不能因此宣稱它在優化精度或訓練穩定性上更好。

預先指定的兩個主要比較，以同一種子的最後 loss 相減，負值代表依狀態減速較好。配對 bootstrap 使用 20,000 次重抽樣，單位為完整的種子配對。

| 比較 | 平均配對差值 | 95% bootstrap 區間 | 改善／惡化 |
|---|---:|---:|---:|
| 依狀態減速 − Momentum | +0.00127 | [-0.00786, +0.01054] | 5／5 |

## 物理與演算法的關係更清楚了

無加能、零外部速度時，對繼承動量乘 a，再作普通 Momentum 更新，等價於：

`v_next = (0.9*a)*v_previous - lr*g_current`。

因此減半那一次更新的有效動量係數是 **0.45**，其餘時刻是 **0.9**；重置相當於當次不繼承舊動量。這是控制動量係數的規則。動量減半保留原方向，瞬間移除 75% 的更新動能；記錄了耗散，沒有瞬間動能守恆的主張。

「何時抑制動量」也需要與既有研究對照。O'Donoghue 與 Candès 的 [Adaptive Restart for Accelerated Gradient Schemes](https://arxiv.org/abs/1204.3982) 已研究高動量造成的週期現象及適應性重啟。本輪是 Momentum SGD 上的部分耗散及帶噪訓練比較，不能直接承接該文的加速法分析，也不能僅因使用物理語言就宣稱新穎性。

你的原始構想來自獨立的物理類比；proposal 可以同時清楚交代這個來源，以及後續找到的相關文獻。學術貢獻仍需要落在可區分的機制、可檢驗的判準與實際證據上。

## 成本與核對

所有方法使用相同模型更新／評估額度。依狀態減速每次訓練的向量診斷平均花 **1.90 秒**；固定時刻減速沒有這項逐步診斷開銷。平均訓練時間為原版 11.25 秒、依狀態減速 11.47 秒、固定減速 9.27 秒。執行期間系統速度有變動，即使打亂順序，這些耗時仍僅供診斷，不作精確速度排名。沒有額外前向不等於沒有額外成本。

- **193 個測試通過**；新增固定時刻控制的原生 SGD 等價性、額度不足時不介入、零額外前向及配對統計核對。
- **50 次正式訓練零數值失敗**；初態配對、全部 400 次更新、額度、來源／資料雜湊及完整 checkpoint 均通過稽核。
- 共 **126 次控制動作**，包含重置 40 次、依狀態減速 46 次、固定減速 40 次。全部加能與診斷模型查詢均為零。
- 30 個控制組在首次介入前，共 **1,304 個觀察點的 loss 與梯度範數逐位相同**；首次介入時的當前 loss／梯度範數也一致。位移統計使用不同加總途徑，最大差異為 **1.04e-17**，以浮點加總誤差容忍核對，沒有把它誤認成參數路徑改變。
- 五組配對彙總已由原始結果重新計算；既有實驗的演算法來源雜湊保持不變。

## 對 proposal 的決定

目前我不會把這個減速判準寫成 proposal 的主要性能優勢。前一輪三個種子的微小收益，在十個新種子上未得到支持，應當如實保留。

可以把已完成的工作定位為：**物理啟發的動量控制規則、成本核對，以及適用範圍與失敗情況的系統性驗證。** 若要再發展新方法，下一個設計需要先提出更明確的機制假說；單憑方向衝突或低進展，還不足以可靠判斷該介入。

本輪保持預先固定的十個種子與門檻，沒有因結果不理想而追加搜尋。一般初態、更多任務、更長訓練，以及介入次數匹配的對照，仍是本輪證據以外的範圍。
