# 什麼時候守恆交換有幫助

固定時程的全量速度交換在 NanoGPT 中先改善了配對訓練 minibatch loss，之後平均差反轉。圖 2 的 checkpoint 補評估把六個改選後變差的案例主要差距定位到固定副本的訓練路徑。這些結果留下兩個可分開驗證的問題。第一，從同一狀態出發，什麼方向的交換比保留速度好？第二，局部改善在支付選擇成本後，能否累積為較好的最終結果？[既存 NanoGPT 結果](../final_nanogpt_exchange_results.md)

## 在同一狀態比較下一步

取兩個等質量 Momentum 副本，令 \(c=(u_1+u_2)/2\)、\(w=(u_1-u_2)/2\)、\(r=\|w\|\)。用 \((c+v,c-v)\) 取代原速度且要求 \(\|v\|=r\)，即可保持總線動量 \(2c\) 與總動能 \(\|c\|^2+r^2\)。保留速度是 \(v=w\)，完整交換是 \(v=-w\)。以下分析允許優化器在守恆球面上選方向。若真實接觸的法線已由位置固定，可選的候選會更少。

令 \(y_1,y_2\) 為保留速度的下一步落點。兩組共用原始參數與同一梯度更新，故換成 \(v\) 後，兩落點只會分別多出 \(d=\mu(v-w)\) 與 \(-d\)。取 \(g_i=\nabla f(y_i)\)，且兩個落點到候選落點的線段都適用共同的梯度 Lipschitz 上界 \(L\)。對所有守恆方向比較同一上界時，須讓這個 \(L\) 涵蓋所有候選所用的線段。假設 \(\mu>0\)。

1. 對兩個落點各套用平滑上界，得到兩副本下一步 loss 總變化
   \[
   \Delta F(v)\le
   \mu\langle g_1-g_2,v-w\rangle+L\mu^2\|v-w\|^2.
   \]
   這是相對於保留速度的比較，兩組有相同的原始狀態。

2. 守恆條件給出 \(\|v-w\|^2=-2\langle w,v-w\rangle\)。這使原先有二次位移的上界，在可行球面上化為
   \[
   \Delta F(v)\le \mu\langle s,v-w\rangle,
   \qquad s=g_1-g_2-2L\mu w .
   \]

3. 若 \(s\ne0\)，Cauchy–Schwarz 給出 \(\langle s,v\rangle\ge-r\|s\|\)。取 \(v^\star=-rs/\|s\|\) 達到等號。因此 \(v^\star\) 在等能量球面上最小化此上界，而且
   \[
   \Delta F(v^\star)\le-\mu\bigl(r\|s\|+\langle s,w\rangle\bigr).
   \]
   括號嚴格為正時，這次交換保證降低兩副本下一步 loss 總和。若 \(s=0\)，保留即達到這個上界的最小值。\(r=0\) 時也只能保留。上式的正裕度是充分條件，實際 loss 下降仍可能發生在界給不出嚴格改善時。

如果 \(f\) 是 Hessian 恰為 \(LI\) 的二次函數，兩個平滑上界都是等式。這時正裕度也刻畫了是否存在守恆方向能嚴格改善兩副本總和。含噪二次 benchmark 可用有無噪聲的對照，直接檢查方向估計偏離這個結果多少。

這個結果把任意交換改成一個有方向與曲率依據的選擇。它也暴露了總和指標的缺口。在 \(f(x)=x^2/2\)、\(\mu=L=1\)、\(w=1\)、\(y_1=4\)、\(y_2=0\) 時，算得 \(v^\star=-1\)。交換後兩個落點都變成 \(2\)，總 loss 從 \(8\) 降到 \(4\)，但原本在最小點的副本從 \(0\) 升到 \(2\)。因此，已有好解時還需要對該副本另外施加 loss 上界。若候選方向無法同時通過總和與個別保護的條件，保留原速度。

當目標是精修或保護時，一步下降是合適的篩選條件。當所有副本都困在差盆地時，越障可能需要先接受短暫上坡。要檢驗這類交換，應另看固定查詢窗內能否到達較好的盆地並留下來。

### 可量測的方向與成本

上述 \(g_i\) 評估在保留落點上。若只重用原位置的梯度估計 \(G_i\)，可把 \(e_i\ge\|G_i-g_i\|\) 的誤差計入上界，附加 \(\mu(e_1+e_2)\|v-w\|\)。在有認證的曲率上界下，\(e_i\) 可由原位置梯度的誤差上界加上 \(L\|y_i-x_i\|\) 得到。在隨機訓練中，單次 minibatch 沒有自動提供這樣的認證。若用配對前向實測候選落點，須把前向成本計入總額度，並另看未用於決策的資料上的表現。

此比較也可用於 AdamW 的輔助位移，前提是兩個基底更新與各自的矩估計保持固定。若交換的是加到基底落點的最終輔助位移，公式中的 \(\mu\) 改為 \(1\)。交換原始 Adam 矩估計時，兩個參數位移一般不會互為相反數，所以上面的守恆球面模型不直接適用。

## 合併成下一批比較前，先固定的問題

| 問題 | 控制與成功指標 |
|---|---|
| 方向有沒有價值？ | 同一交換前狀態，同一批資料，配對比較保留、完整交換、守恆隨機方向及依上界選方向。先報下一步 loss 總差與好副本個別 loss 差。 |
| 何時該保留？ | 分開看停滯、已辨認好解及仍在穩定下降的狀態。記錄介入觸發率、好副本的暫時偏離、恢復以及候選檢查成本。 |
| 局部收益能不能累積？ | 全程比較由相同初態與批次流開始，獨立副本依同一 validation 規則選模型。分項記梯度與額外前向，測試資料只用於最後評估。 |

分析時用共同狀態或種子組作配對單位。合成問題的盆地標籤只用於判定越障及分層。神經網路上若用停滯觸發，規則應只讀當時可得的訓練量，並與同一預算的固定排程比較。若一步收益成立但最終表現未改善，再比較收益消失在後續梯度更新、選擇成本，還是 validation 到 test 的落差。

首選 DeepOBS 含噪二次問題來隔離方向及曲率，COCO/BBOB 的 Rastrigin 比較越障，CIFAR-10 小型 CNN 比較訓練收益能否延續到驗證與測試。三者分別回答不同問題，應在同一輪先鎖定要比較的策略、預算及失敗判準，再一起執行。
