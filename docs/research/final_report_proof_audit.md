# EE 5239 報告證明核對

## 反彈返回映射與穩定性

1. 固定能量 \(gH\) 後，取井底垂直向上的速度分支。因 \(v=\sqrt{2gH}>0\)，根號內在原點附近為正，出射速度可微。
2. 將自由飛行的高度減去牆面高度，得到 \(t[w-\kappa xu-(g+\kappa u^2)t/2]\)。括號在 \(t=0\) 為正並嚴格遞減。第一個正根以前間隙為正，根處的時間導數為 \(-(w-\kappa xu)<0\)，所以確為首次入射，而非切觸。
3. 正規化法線後代入彈性反射。原點處法線斜率和水平速度均為零，只剩法線斜率的微分乘上 \(-2v\)。於是 \(dX=dx+T\,du\)，\(dU=du-2v\kappa\,dX\)，其中 \(T=2v/g>0\)。
4. 令 \(y=x+Tu\)。線性更新為 \((x,y)\mapsto(y,\tau y-x)\)，\(\tau=2-8\kappa H\)。在 \(|\tau|<2\) 時，保留下來的二次量 \(Q=x^2+y^2-\tau xy\) 為正定，故兩座標及 \(u=(y-x)/T\) 都有界。在 \(\tau<-2\) 時，存在特徵值小於 \(-1\)，沿其方向的擾動無界。
5. 邊界 \(\tau=-2\) 必須獨立處理。\(M+I\ne0\) 且 \((M+I)^2=0\)，故 \(M^np=(-1)^n[p-n(M+I)p]\)。取 \(p=(0,1)\) 得 \(\lvert x_n\rvert=nT\)。光看譜半徑等於 1 會漏掉這個情形。

結論適用於固定能量、無阻尼的線性化軌跡。一般牆面的 Hessian 分解是正文的解析延伸。實際有限擾動的保護界仍需控制返回映射餘項及接觸誤差。形式化對應見 [返回 Jacobian 與譜分析](bounce_spectrum_verification.md)。

## 二次目標的速度交換

1. 梯度是仿射映射，因此副本的平均梯度等於平均位置的梯度。交換只排列更新後的速度，故平均位置和平均速度滿足同一個封閉遞迴。這一步要求共同、確定且未裁切的二次梯度。
2. 固定交換前的參數，比較同一對副本的保留及交換落點。二次展開後，位置常數相消，兩項純速度二次量只是互換。剩下的交叉項 \(\mu(z_i-z_j)^\top A(u_j-u_i)\) 可正可負。
3. 對 \(f(x)=x^2/2\)、\(\eta=\mu=1/2\)，由 \((a,-a)\) 和零速度真的走一步，得到 \((a/2,-a/2)\) 及 \((-a/2,a/2)\)。第二步保留時兩邊都到零，交換時兩邊各有 \(a^2/8\) 的 loss。此狀態可由共同初態到達，且 \(\eta L=1/2<3/4=1-\mu^2\)。

這個反例證明守恆與充分穩定步長都不能保證交換優於保留。它沒有判定 NanoGPT 個別事件的內積符號。形式化對應見 [二次交換核對](quadratic_exchange_verification.md)。

## Momentum、反射與交換的收斂率

1. 須先用全族群的平方位移和來控制交換後的動能項。個別副本的速度可以變大，個別不等式不能取代族群守恆。
2. 上坡反射縮小步長範數，並使梯度內積不增加。令 \(c=(1-\eta L)/(2\eta)>0\)，把平滑性界與位移項相加後，\(L/2+c=1/(2\eta)\)。展開 \(s=p-\eta(g+\xi)\) 得到 \(-\eta\|g\|^2/2\) 和誤差交叉項 \(-p^\top\xi\)。由 \(a\in[0,1]\)，\(\|p\|^2\le\mu^2\|u\|^2\)，舊動能留下嚴格負的係數 \(-(1-\eta L-\mu^2)/(2\eta)\)。
3. 精確梯度時把一步不等式加總，再用 \(\Psi_T\ge0\)，得到平均梯度平方的 \(O(1/T)\) 界。幾何率另需梯度支配條件，同時控制 loss 差與位移項。
4. 有偏誤差時，以 Young 不等式吸收一半的負位移項。條件中心化時，可以直接讓交叉項的條件期望為零，但 \(p=\mu au\) 須在抽當前 batch 前可測。依當前 batch 判斷是否減速時，仍可使用逐路徑誤差界。原稿期望式的 \(\Psi_0\) 只適用固定初態，已改為 \(\mathbb E[\Psi_0]\)，並補上初始能量可積的條件。

Lean 的中心化結果涵蓋有限抽樣。一般的條件期望論證寫在正文所引附錄。NanoGPT 的 \(L\) 未經認證，亦未確認裁切後梯度無偏。形式化對應見 [收斂證明核對](optimizer_convergence_verification.md)。

## Adam 家族候選步與下降檢查

1. 梯度步 fallback \(d=-\eta G_t\) 同時通過兩個檢查。第一個使用 \(\eta L\le1\)，第二個直接使用 \(\|d\|=\eta\|G_t\|\)。這也涵蓋 \(G_t=0\)。
2. 把真梯度換成 \(G_t\) 時，內積至多多出 \(\varepsilon_t\|d\|\)。代入範數檢查，得到 \(-\eta\|G_t\|^2/2+2\eta\varepsilon_t\|G_t\|\)。
3. 用 Young 不等式與 \(\|\nabla f(x_t)\|^2\le 2\|G_t\|^2+2\varepsilon_t^2\)，得到 \(-\eta\|\nabla f(x_t)\|^2/8+17\eta\varepsilon_t^2/4\)。加總後除以 \(\eta T/8\)，誤差係數為 \(34/T\)。幾何率仍需梯度支配。

保證來自檢查和 fallback，適用於任何供給候選步的優化器。要證明相同預算下優於原 AdamW，還需比較被接受的步在後續造成的收益、檢查成本和泛化表現。形式化對應見 [收斂證明核對](optimizer_convergence_verification.md)。
