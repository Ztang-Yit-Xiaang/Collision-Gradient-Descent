# 高維測試與原失敗案例的診斷

## 本輪問題

一維雙井未顯示優勢，可能是反射與越障需求衝突，也可能涉及額外高度狀態和位能定義。提高維度不能自行區分這些原因，因此保留原結果、先檢查事件，再加入尺度可比的高維測試。

原 seed 0 的主動反射在第 3 步反轉越障的上坡速度。融合版第一次接觸前後的水平速度約為 -0.397 和 -0.096，速度轉向有接觸點法線的幾何來源，並非單純的反射公式符號錯誤。普通方法的位能為 `mixing*f`；融合版在表面的位能為 `f`，因此相同水平作用力並不表示有效越障能量相同。

## 固定實驗條件

- 維度 100、1,000、10,000、100,000。
- 每個設定三個種子，每法最多 500 大步；各法共用函數與梯度預算上限，解析路徑另記。
- 方法為普通 momentum SGD、匹配判準的 restart、主動反射、融合接觸，以及初始額外能量控制。
- `h=0.05`、`beta=0.995`、`mixing=0.5`；主動版仍採 `epsilon_c=0.1`、`epsilon_f=0.001`、`patience=3`。
- 全部結果保留，包括接觸錯誤、預算停止與未成功越障；不依結果修改參數。

## 高維目標

令 `r=sqrt(d)*Qx`，`Q` 是隱式正交映射。雙井使用

`mean( (r_i^2-1)^2/4 + 0.05*r_i + coupling*(r_i-r_(i+1))^2/2 )`，

其中 `coupling` 分別為 0 與 0.2。週期相鄰耦合提供真實的非可分離項。其全域最小值由所有井座標均取同一個最低標量極小點得到；耦合項非負且此時為零。

Rosenbrock 使用

`mean( (r_(i+1)-r_i^2)^2 + 0.01*(1-r_i)^2 )`。

已知最小值為零。二次控制使用特徵值在 0.01 到 1 之間的結構化旋轉橢球，也已知最小值為零。

所有座標均參與目標，沒有只保留第一個座標的雙井再補上大量零座標。初始總動能固定；尺度設計避免把更大的初始能量誤認為高維帶來的好處。

## 方法與數值求解的邊界

不更改兩個優化方法的更新規則，只新增純量診斷和精簡軌跡儲存。預設純二次函數移除不必要的密集單位矩陣配置；新目標的力及路徑多項式採向量化實作。這是讓高維測試可執行的工程修改，不是針對結果設計新演算法。

這輪仍依賴合成函數的解析路徑查詢，不代表黑箱神經網路曲面求根已完成。仍未加入多粒子全域事件排程，不能據此否定或證實原始的群體動量交換假說。

## 失敗記錄與步長檢查

十萬維 Rosenbrock 的初次批次觀察到主動反射數值溢位。原先執行器沒有將浮點失敗隔離為單次實驗的停止原因，因此批次中斷。修正僅涉及失敗記錄及續跑，沒有變更兩個方法的數學更新或原批次超參數；已完成的 225 次結果沿用，最後一組重新執行。

發散執行不進入有效結果中位數，但其停止點、已用成本與失敗次數仍完整保留。不能把某個方法在發散之前曾到達的低 loss 當作可靠結果。

另外以 0.05、0.025、0.0125 的步長檢查相同的十萬維 Rosenbrock 初態，固定物理時間 25。設 `beta(h)=0.995^(h/0.05)`，保留連續阻尼率；主動版的觀察步數設為 `round(0.15/h)`，loss 門檻按 `h/0.05` 縮放。較小步長花費更多評估，這組結果只診斷時間離散與穩定性，不用來宣稱計算效率更高。

### 對設計的含義

目前的物理接觸公式滿足瞬間彈性反射，但不能由此推出較好的越障能力。令接觸點梯度為 `g`，入射條件為 `vz-g·v<0`，則水平速度改變為

`delta_v = 2*(vz-g·v)*g/(1+||g||^2)`。

因此接觸的水平衝量沿局部負梯度，可能打斷已有的上坡越障速度；增加維度不會改變這個局部方向。主動版也可能把越障所需的上坡判作需要介入的事件。另一方面，二次橢球上兩種反射都優於普通動量，說明這個機制可能適合抑制不利慣性，但目前沒有證據支持它能普遍改善越障。

後續若保留物理主張，應先獨立驗證原提案的粒子間動量交換，並改善高曲率及持續接觸的積分穩定性。這輪只有三個種子、固定超參數與合成目標，尚不能否定整個原提案，也不能外推到 NanoGPT。
