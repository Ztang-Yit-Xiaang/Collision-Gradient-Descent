# 最終 NanoGPT 比較：四副本守恆速度交換

## 比較方式

十個正式種子組 5110–5119，各跑四個交換副本、四個獨立 Momentum SGD 副本及一個 AdamW。兩個 Momentum 組的各副本初態與 minibatch 流逐一配對，完成 100 更新後以 32 個固定 validation minibatch 的 loss 選出副本。AdamW 從第 0 副本的初態與 minibatch 流跑 400 更新。所有方法每種子組都是 400 次 minibatch 梯度（204,800 個訓練 token 位置），最後在同樣的 32 個 test minibatch 評估。每個 Momentum 組另需 128 次 validation forward，AdamW 需 32 次。模型、資料切分及學習率沿用前輪，未重新調參。測試資料切分沿用已使用過的資料，正式種子為新種子。[完整協議](superpowers/specs/2026-11-16-final-nanogpt-exchange-design.md)

## 交換及守恆核對

每個種子組在各副本完成第 20、40、60、80 次更新時做兩次成對交換，十組共 **80 次**，所有配對的交換前速度都不同。原生 SGD 緩衝區的雜湊在交換後完全對調，模型參數雜湊保持相同。兩 Momentum 組首次交換前 20 個訓練觀察與邊界參數雜湊逐位相同。用 float64 核算，線動量最大分量殘差和總動能最大絕對差均為 **0**。每對實際轉移動能的絕對值中位數為 0.009071（平方參數位移單位），交換的外部衝量、做功、耗散均為零。平常的梯度與動量衰減改變繼承速度，詳見報告第 8 節的能量收支。

工程種子 5100 驗證八次交換與預算，排除在上述統計外。正式共 90 個實際副本訓練、30 個方法結果、12,000 次梯度、2,880 次 validation forward、960 次 test forward，無訓練失敗。另有工程 9 個副本、1,200 次梯度、288 次 validation 及 96 次 test forward。獨立稽核核對全部 99 個 checkpoint、來源壓縮檔、配對前綴、選擇規則、成本及交換資料，未額外執行模型查詢。專案測試 290 項通過。

此結果支持兩件具體的事。完整速度交換可以在原生 Momentum SGD 上實際運作，且逐事件守恆。在這個模型、語料、固定學習率及排程下，它使選出的最終模型平均 loss 上升。報告保留此結果，研究止於本次比較。

| 5111 | 3 → 2 | +0.04834 | +0.03650 | −0.01669 |
| 5112 | 2 → 3 | −0.01260 | +0.03261 | −0.04402 |

| 5115 | 2 → 3 | +0.03276 | +0.01454 | −0.01569 |
| 5116 | 2 → 2 | +0.00037 | +0.00232 | 0 |

| 5118 | 3 → 0 | +0.05004 | +0.07113 | −0.03005 |
| 5119 | 1 → 0 | −0.02571 | −0.00735 | −0.02212 |

在 test 變差的八組中，兩組選到同一個副本，六組改選。固定 \(j\) 的 validation loss 八組全升，平均 **+0.03296**。重新選擇把交換組的 validation loss 平均降 **0.01076**，最後選出副本的 validation 差平均 **+0.02220**，七組上升。一組例外是 5115，重選後 validation 差為 −0.00115，test 差為 +0.03276。相同分解也可寫在 test loss 上，但改選的組在交換臂只存了 \(T_S(i)\)，缺少同一臂的 \(T_S(j)\)，重選對 test loss 的影響方向因而未知。

第 21 步的訓練 loss 是該次更新前算的，40 對都相同。交換後的速度第一次用在第 21 步更新，第 22 步才觀察到交換造成的 loss 差。八個最終 test 變差種子組裡，第 22 步有 **27/32** 對副本的訓練 minibatch loss 下降，平均差 **−0.03307**。第 22–25 步平均差 **−0.02616**，第三次交換後第 62–80 步平均差 **+0.01985**。後段包含先前交換與路徑累積效應，不能單獨歸因於第三次交換。相同種子、相同副本和步數使用相同 minibatch，副本計數為描述性統計。

報告修訂時以全部十組重算相同窗口。第 22 步有 **32/40** 對副本的訓練 minibatch loss 下降，平均差 **−0.02848**，第 62–80 步平均差為 **+0.01661**。每一項差值都配對相同種子、副本及步數，再對指定窗口取平均。這個事後彙總使用已保存的訓練歷程，新增訓練與評估查詢皆為零。

在共同參數和相同 minibatch，設 \(a,b\) 為保留與收到的速度，\(\tilde g\) 為未裁切梯度。兩個候選更新的一階 loss 差恰是 \(\mu\tilde g^\top(b-a)\)。存檔只有梯度範數、速度差範數、轉移能量與雜湊，無法從這些方向摘要計算內積。上述追查只讀正式批次的 runs.json 與 paired_outcomes.json，未執行訓練或 checkpoint 評估。
