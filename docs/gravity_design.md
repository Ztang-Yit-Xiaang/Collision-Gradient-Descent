# 純重力模型：本輪設計與驗證

使用者同意再測試保留垂直重力的版本。本輪先隔離單粒子的重力與地形接觸；多粒子碰撞仍是後續獨立問題。

## 模型

質量為 1，固定地形 `z >= ell*f(x)`，位能 `U=g*z`，自由飛行作用力 `(0,-g)`。不另施加水平負梯度力，不以 loss 上升或耐心計數觸發反射。表面法線為 `(-ell*grad(f),1)` 的單位化向量，入射碰撞完全彈性。

自由飛行使用精確拋體軌跡 `x(t)=x0+t*v`、`z(t)=z0+t*vz-g*t^2/2`。合成函數提供沿水平直線的多項式，完整搜尋入射接觸根，碰撞後繼續剩餘時間。這不需要把重力先施加整步再直線位移。

表面上且法向速度為零時，令 `a=grad(f)`、`c=v^T Hess(f) v`，所需支撐力為 `N=(g+ell*c)/sqrt(1+ell^2*||a||^2)`，水平加速度為 `-ell*(g+ell*c)*a/(1+ell^2*||a||^2)`。`N>=0` 時持續接觸；`N<0` 時離地。方向二階導數由現有解析路徑多項式取得，不建立密集 Hessian。

接觸運動採 RK4 與步長加倍誤差估計，並檢查能量殘差。離地事件以支撐力過零定位；不允許負支撐力把粒子吸在地形上。接觸約束用表面座標表示，浮點層級的入模約束修正另外記帳。無法解析的事件明確停止，不以速度縮放維持能量。

每個觀察大步開始施加一次各向同性速度阻尼 `beta`，阻尼改變的動能獨立記錄。這是離散阻尼模型；縮小觀察步長時需按相同阻尼率調整 beta。自由飛行重力做功為 `g*(z_before-z_after)`；固定表面的理想法向力與彈性衝量不做淨功。機械能仍量測數值殘差。

## 驗證順序

1. 平面自由落體、平面精確反彈、不同斜率、持續滑動的解析解。
2. 曲面持續接觸的能量誤差、凸峰離地、掠碰與中途穿透、初始非法狀態、成本與預算。
3. 使用固定初態、固定參數，比較普通動量、主動反射、既有融合模型與純重力模型。分開記錄時間、值／梯度／路徑成本及失敗；不可只比較大步數後宣稱等成本。
4. 加入相同地形表面位能係數及總初始機械能的動量控制，並保留相同水平初態的控制。兩者回答不同問題。
5. 先做物理診斷與低維預檢，再重跑具有全座標活動的高維目標。固定預算的曲線及固定時間的曲線分開呈現。

## 限制

本輪使用確定性、解析多項式合成目標，尚未解決神經網路的一般接觸定位與隨機表面變化。只通過守恆與穩定性測試不能證明優化有效；純重力即使比前版穩定，也可能仍不如普通動量。
