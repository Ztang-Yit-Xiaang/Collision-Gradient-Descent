# E54｜第四個保存點可能越線時加查

沿用 E53 的 168 組初態，在 \(t=1.54\) 決策並追到 \(t=5.00\)。E54 用 E52 同一個跨接觸 loss 上界多估一個保存點。四點全安全時略過精確路徑；第四點有風險才允許把精確預測延到第四點。延伸時重用現有路徑多項式，若該步遇到第四次自然反射，依同一牆面模型重建出射速度。只有精確預測保存點會越線才在原初態做受限轉移。[預定協議](superpowers/specs/2026-11-15-fourth-point-bound-design.md)

## E53 剩下的 21 組

21 組在第三個保存點 \(t=1.75\) 都還在門檻內，沿雙井橫向上坡，第四點的 loss 全都上升。七組在第四點 \(t=1.80\) 首次越線，第三點的 loss 增量已達門檻的 74.0%–99.5%，中位數 91.9%。其中三組在這兩點之間再接觸地形，一組要跟到第四次反射才能確認。其餘 14 組在第三點只有門檻的 18.6%–62.2%，中位數 44.3%，第四點上界都低於門檻，首次越線為 1.85–2.25。這 14 組後續都曾恢復，12 組再越線，14 組在 5.00 都回到門檻內。[21 組時序與配對](../output/collision_fourth_point_bound/previous_unprotected_cases.json)
