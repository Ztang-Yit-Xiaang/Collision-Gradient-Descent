# E40 補充｜受限轉移後的壞井探索

使用 E40 同一批配對。只計初始位於壞井的三顆探索粒子。越井定義為沿原地形的旋轉縱向座標從鞍點邊界的壞井側進入好井側，同一粒子每次進入皆計。由保存位置、精確反彈點及轉移位置還原分段直線，在段內定位越井時刻。達標沿用原門檻，需同時進入好井且 loss 不高於好井最小值加 \(10^{-4}\)，約 −0.05051011。首次達標先在保存點和精確接觸上辨認。[衍生方法](research/e40_exploration.py) · [逐組逐粒子資料](research/e40_exploration/per_context.json)

越井的是完全相同的粒子，且至 \(t=2.00\) 仍在好井側。20 組介入中，五顆越井粒子都在轉移之後才越井，配對時刻有 2 個略早、3 個略晚，最大差 0.00203。全 480 組的兩分支最靠近好井的縱向座標均約 −0.59727。此地形在好井邊界到該座標之間，縱向 loss 下界約 0.07358，橫向項非負，因此連保存點之間的軌跡也達不到門檻。越過鞍點後，這批仍離低 loss 區有距離。

在 20 個介入配對中，每組取三顆探索者最低的最終 loss，受限轉移有 9 組降低、11 組升高，配對差（受限減 E37）中位數為 \(+1.75\times10^{-4}\)，範圍 \([-0.00171,+0.00184]\)。上表的 0.183871 和 0.182841 分別是兩組中位數。歷史最低 loss 18 組相同，2 組升高，最大差 \(8.00\times10^{-5}\)。未介入的 460 組兩政策沿同一條路徑。

轉移當下三顆探索者合計增加的水平動能，每組中位數 \(1.17\times10^{-5}\)，範圍 \(4.39\times10^{-6}\) 到 \(2.29\times10^{-5}\)。逐顆看有 31 顆增加、29 顆減少。這批結果支持保護好粒子時維持到 \(t=2.00\) 的越井次數。探索者最終 loss 有小幅雙向變化。兩政策的達標率皆為零，因此這批無法比較達標速度或衡量達標能力是否保留。[完整指標](research/e40_exploration/summary.json)
