# E25｜用初始 loss 差距決定是否轉移動量

父實驗 E24 在 κ=8、相同固定高度 .025 下，一律保留／轉移的好粒子途中偏離分別 20/20、0/20，壞井最後達標 12/20、8/20。E25 檢查只用已付費的四個初始 loss，能否保護好解並保留壞井的探索能力。

- 沿用 E24 的旋轉二維雙井、κ=8、縱向尺度 1、四顆單位質量粒子、偏移長度 .001、兩種起始情境、模板粒子 0 水平動能 .001。三政策均給初始 loss 最小者高度 .025，其他三顆均分高度餘額，總高度 3.2、總動能 .6、總線動量 0。沿用同一重力 .5、步長 .05、阻尼、彈性地形反射與凍結的 E24 轉移規則。只有初始速度配置可變，沒有在線控制、二體碰撞或運行中補能。初始轉移比較同位置前後的 E、K、線動量與角動量，角動量只記錄變化。
- 四個 loss 排序為 a≤b≤c≤d，分數為 (c−a)/max(d−b, 1e−12)。最低點由首次 argmin 選出。有條件政策在分數大於或等於固定門檻時轉移。條件、真井底、初始座標及速度均不進入決策。
- 開發只讀 E24 κ=8 的 20 組既有種子 1600–1619，固定高度 .025 的兩個實跑分支。評估門檻 1、3、10、30、100、300、1000；先最少好粒子途中偏離或求解失敗，再最多壞井最後達標，再最少在壞井轉移，完全同分採較小門檻。開發結果只供設定規則，記錄全部候選和來源雜湊。鎖定後工程預檢 1690，正式 1700–1719。預檢只驗工程和物理；正式結果出來後不調門檻或增減種子。
- 預檢每政策 1200 查詢／80 步，正式 6000 查詢／500 步，無結果導向提早停止。每個 context 實跑保留與轉移兩個分支，條件式政策只讀它必然執行的同一條確定性軌跡。正式 40 contexts、80 實跑、40 條條件式衍生結果，20 獨立配對種子。每政策自身計四次初始值查詢，兩實跑共用一次，無額外梯度探針。正式 solver 至多 479840 查詢，另 120 次評分參考查詢；預檢分別至多 4792 與 6。共四個 worker，數值執行緒各一。稽核另計解析目標與梯度評估。資料由封存的種子與程式產生，保存來源封存、環境、設定、原始軌跡、事件及逐軌跡能量收支。
- 主評分採同查詢預算，另以每 context 的共同最短已保存時間重算。好粒子途中曾明顯偏離初始解的次數以原粒子的任一已保存 loss 超過自身初值 1e−4 計數。好粒子最終達標與壞井最終／歷史達標分開報，沿用 E24 目標與盆地判準。保存配對切換、當前與歷史最佳 loss。求解失敗單列，成功指標視為失敗，偏離篩選另加失敗。
- 初步成功條件為無 solver 失敗、一律保留的壞井最後至少 5/20、一律保留與轉移在好粒子途中偏離至少差 5/20。條件式政策在好粒子途中偏離與最後達標各至多比一律轉移差 2/20，壞井最後至多比一律保留少 2/20；另記是否超過一律轉移的壞井達標。這是描述性篩選，20 個種子不是統計非劣或跨地形證明。此地形的兩種初始雲可能由 loss 差距輕易分開，正結果只支持此固定分布與初始化規則。
