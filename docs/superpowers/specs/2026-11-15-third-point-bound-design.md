# E52｜在第三點可能越線時才加查

承接 E51。先用封存反彈事件及保存 loss 試算三點上界。規則和常數依雙井的已知解析地形及物理式固定，未用封存未來狀態作決策，也未調門檻。離線預期略過 21 組更晚越線與三組安全案例，省 92 次查詢，保住原本防止的 16 組。這批是同樣本機制重播。

從同一 \(t=1.54\) 決策點對 168 組新付預測，沿用 E51 的機械能篩選、保存時間 1.65／1.70／1.75、精確查詢、最多三次自然反射、\(10^{-4}\) 門檻與受限轉移。通過原機械能篩選的軌跡沿用原決策。對其餘案例，用首反彈狀態及既有阻尼求前兩點與第三點的 loss 上界。三點皆證明低於門檻才略過反彈後的路徑。前兩點安全時，第三點可能越線才加查；無證書時保留完整 E51 查詢。若選定分支未封存，由相同初態續跑到 5.00。其餘重用 E49–E51 封存分支。

對每個保存點的剩餘時間 \(T\)，\(D\) 為累乘速度阻尼後的有效飛行時間；從機械能及地形已知最低點推出全速度上界 \(V\)。牆的垂直衝量和有上界 \(J=\max(0,V-v_z+gT+V\sum(1-\beta))\)。在雙井旋轉座標中，先翻轉橫向座標使 \(y\ge0\)，要求初始橫向速度向外。法向碰撞在 \(y\ge0\) 只會降低向外速度，故 \(Y=y+v_yD\) 是未翻向前的上界。若 \(y-skYJT>0\)，則在此時間內無法穿過零，\(Y\) 也界住實際位移。\(s\) 是地形高度比例，\(k=8\) 是橫向曲率。

谷底方向以全域最小點 \(x_\star\) 為中心。取半徑 \(r=2(|x-x_\star|+|v_x|D)+10^{-12}\)。在半徑 0.01 的已知局部範圍內用解析曲率上界 \(M\)；若 \(r\le0.01\) 且 \(sMJT\le0.5\)，累積衝量造成的位置變化至多 \(r/2\)，故實際座標留在該半徑內。三個保存點各有 loss 上界 \(f_\star+Mr^2/2+kY^2/2\)，略過時需要低於門檻至少 \(10^{-12}\)。這個證書依賴雙井結構、獨立粒子、固定牆和耗散；速度界的最低 loss 再放寬 \(10^{-12}\) 以容納浮點誤差。

工程沿用 E51 六初態，加上 s3213 late_low 的近門檻陽性與 s3216 late_low 的安全案例，主批全 168 組、種子不變。每組預測至多七次，新續跑各最多 4096 次，工程總上限 32,824，主批 689,304。求解失敗或達上限停該批並留檔。成功標準為保住 E51 的 16 次新增防止及全部原有預防、減少政策查詢，27 組安全案例無新增不必要轉移。分開報預測、總成本與實付；終點 loss 和最佳保存值各報。若有新轉移，外部供能為零，稽核總動能、線動量與好粒子水平動能。重力做功、牆面衝量、阻尼、角動量變化和殘差分列；重用則連結原帳本。
