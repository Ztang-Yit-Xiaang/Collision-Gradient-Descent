# E51｜預測到第三個保存點

承接 E50。同一批 168 初態與決策時刻 1.54，追到 5.00。封存 37 組有 16 組首次在第三個保存點 1.75 越線，其餘 21 組更晚，據此固定檢驗第三點窗口。封存軌跡只供分組、稽核及重用相同決策分支。

在首接觸算自然反射後，若好粒子的總機械能上界 `z + K/g`（地形高度比例為 1）已低於 loss 門檻，略過反彈後路徑。這個上界適用於獨立粒子、靜止彈性牆及耗散阻尼。其餘逐段預測準確碰撞、反射速度與保存點 loss，在沒碰撞的多個保存步間重用同一方向多項式，按原時鐘施阻尼。首接觸後最多再跟兩次反射，第四次接觸時截斷。到達第三個保存點或先預測任一保存點越線即停止。E50 原單段曲率篩選維持為對照，E51 以跨接觸有效的機械能上界作查詢篩選。新規則在原決策時刻採同一受限轉移。

工程固定六組 `s3200 energy_safe/early_high/late_low`、`s3202 early_low/late_mid`、`s3209 early_low`，涵蓋安全、原及新增警報及窗外越線。主批用全部初態，無新種子或調參。新預測逐組實付。若同一分支在 E49／E50 已封存，直接重用；新增受限分支實跑到 5.00。逐組報新增和失去的保護、先前安全者的額外轉移、首次越線、含精確接觸的偏離、恢復／再越線、終點與歷史最佳 loss。分開核算預測、含設定及選定續跑的總成本與實付。

每初態最多七次預測及一次 4,096 查詢的續跑，工程上限 24,618，主批 689,304。求解失敗或超額須記錄並停止。機制標準是新增保護、保住 E50 原有防止且安全組無不必要轉移。另分析 16 組第三點與 21 組更晚的結果。介入時零外部供能，稽核總動能、線動量及好粒子水平動能；重力做功、外部牆面衝量、角動量變化、阻尼耗散和數值殘差單列。
