# E26｜初始 loss 差距重疊時的動量轉移

E25 在同一合成分布上把含好點與全壞井情境完全分開，但壞井裡僅轉移達標 5 次、僅保留達標 3 次。E26 固定 E25 門檻 100，檢查 loss 差距一樣時哪些決策失效，以及初始動能或短程反彈能否排序轉移的效果。

- 保留 E25 的旋轉二維雙井、κ=8、重力 .5、步長 .05、阻尼、彈性地形反射、最佳粒子高度 .025、總高度 3.2、總動能 .6、總線動量 0、轉移映射。只有初始化，運行中無補能或二體介入。每個狀態內配對分支的初始總能量一致，跨情境的 loss 絕對基準與位能可不同。
- 每種子四個狀態，交叉起始情境與預定 loss 分數 30、300。粒子 0 如 E25 從好井或壞井井底加相同 .001 位移。其餘三顆均在壞井的縱向井底，利用橫向位移讓它們比粒子 0 多出 loss `[.11−s/2, .11, .11+s/2]`，其中 `s=.11/分數`，橫向符號沿用 E25 雲的符號。兩情境因此有相同的相對 loss 向量與分數。每種子所有四狀態用完全相同速度，依種子除以四的餘數取粒子 0 初始動能 [.0002, .001, .004, .016]，仍用 E25 方法匹配總動能和線動量。規則不讀取情境標籤。此構造把壞井粒子的橫向位移拉大，報告因此只能解釋這個重疊壓力測試。
- 工程預檢種子 1890，8 條實跑，每分支 1200 查詢／80 步。開發種子 1900–1911，96 條。正式種子 1920–1939，160 條。開發及正式每分支 6000 查詢／500 步，四 worker、各數值執行緒一。每個狀態共用實算四個初始 loss，每分支各按四次計價。每狀態另記 4 次生成／評分參考值，包括三個井的臨界位置和粒子 0 的起始值。無結果導向早停、補跑或追加參數。正式 solver 上限 959680，另 320 次生成／評分查詢；開發上限 575808，另 192；預檢 9584，另 16。正式有 80 條 E25 規則的衍生結果及 20 個獨立配對種子。每階段另計獨立稽核的解析值與梯度。
- 主分析沿用 E25 的好粒子途中曾明顯偏離初始解的次數（loss 上升嚴格超過 1e−4）、最終達標、壞井歷史／最終達標。每種分數分列一律保留、一律轉移、E25 規則，以及兩分支達標切換；並報每狀態共同最短時間的結果。機制反例要求同種子兩情境分數相同且規則作同一決定。低分含好點若保留出現途中偏離，且轉移能保持並最終達標，記作一次錯過保護。高分全壞井若保留最後達標而轉移沒有，記作一次誤轉移。兩種各自至少 5/20 視為可重現的反例；基準表亦保留逆向效果及兩種平手。
- 短程訊號只做離線排序，讀一律保留分支前 10 個已提交步驟（0.5 物理時間）內，粒子 0 的地形水平衝量向量和的模長。另比較初始 loss 分數與粒子 0 初始動能。用分數設計值 30、300 作排序，避免浮點誤差打破本應平手的分數。只有兩分支都無求解失敗、保留分支有完整 10 步、兩動作的結果不同才做排序。含好點的成功定義為原好點最後達標且途中未越門檻，全壞井以最終群體是否達標。分情境在開發資料選擇各分數排序方向（轉移較好排前，AUC <.5 才反向），平手計一半。開發與正式每個方向至少五筆、來自至少五個不同種子，才把正式 AUC 和相對 loss 分數的差寫作可解讀；正式差達 0.10 記為後續候選。這是機制篩選，兩個分數情境可共用種子，無統計優越宣稱。前綴在觀察完成後才可用，保存實際查詢成本。它並未作為時間零的決策輸入，也未把動作回溯至初始化執行。
