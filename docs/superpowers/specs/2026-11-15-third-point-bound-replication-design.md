# E53｜用新種子驗證 E52 三點上界

承接 E52 的同批機制重播。在同一雙井、同一 E49 分層生成機制中，工程種子固定為 3290，主批種子固定為 3300–3323。每種子各跑七個早／晚接觸與比值條件，含一個低能量安全對照。共七個工程初態、168 個主批初態。事先鎖定 E49 的時段、比值範圍及 PCG64 生成方式，包含會在第三個保存點才越線的條件。所有初態都入組，由新跑的保留軌跡按首次越線時間事後分類，不調參或依結果換種子。主批和工程種子分離。

E51 與 E52 沿用 E52 封存同版預測器，分別從同一 \(t=1.54\) 初態實付預測。兩政策均用三點窗口、最多三次自然反射和原 \(10^{-4}\) 門檻，E52 額外對三點使用跨接觸上界。每組都跑保留至 \(t=5.00\)，至少一政策警報就從原狀態新跑一次受限轉移，兩政策同選則共用該軌跡。所有初態與動力學續跑在此輪生成。保存點首次越線於第三點的案例單列，並核對上界和精確預測。安全是保留分支所有保存點在門檻內；對它轉移屬不必要，另報含精確接觸結果。

比較 E51 原防止案例保留數、第三點陽性保留數、不必要轉移及提早／新增越線，另報最終與歷史最低 loss、恢復及再越線。各政策總查詢包含設定、自己的預測及所選續跑，即使相同續跑只實跑一次。實驗實付按真正的兩次預測和各唯一續跑計。成功標準為主批包含一路安全與第三點陽性、保住 E51 原防止、無新增不必要轉移，且預測及總查詢下降。不符合照實記錄。

每初態四次設定、每政策最多七次預測、保留與受限各不超過 4096 次。工程上限 57,470，主批 1,379,280。到 5.00 停止，求解失敗或查詢耗盡時記錄原因並停止該批。受限轉移外部供能為零，核對總動能、總線動量及好粒子水平動能。重力做功、牆面衝量、阻尼耗散、角動量及殘差分列。以保留分支事件核對自然反射及每個可計算的 loss 上界。
