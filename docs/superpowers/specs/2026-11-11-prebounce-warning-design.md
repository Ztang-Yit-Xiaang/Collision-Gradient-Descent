# E28｜第一次地形反彈前的好粒子偏離預警

E27 的好粒子 20/20 次在首次反彈前就已觀察到明顯偏離。E28 檢查以初始速度與最初兩步的 loss，能否在偏離發生前預警。本輪只比較預測，所有規則讀相同的無介入軌跡。

- 沿用 E27 含好點的二維旋轉雙井、κ=8、初始相對 loss 分數 300、粒子 0 從好井底移開 .001、高度 .025、重力 .5、步長 .05、相同阻尼與地形反射。四顆單位質量獨立粒子。粒子 0 的初始水平動能取 0.00001、0.00008、0.00015、0.00025、0.0004、0.001，方向與同種子其他初態共享。用原始速度生成器把總動能維持 .6、總線動量 0。初始垂直速度為 0，運行中無轉移、二體碰撞或供能。
- 預檢種子 2190，開發 2200–2219，正式 2230–2269。每種子六種動能各實跑一次，分別 6、120、240 條。每條最多 8 步／300 次 solver 查詢，走到 .40 以記錄第一次反彈和最後一個反彈前觀察點。每條四次初始 loss 實算並計費，另四次生成／評分參考。即使不同動能的初始點相同也分別實算，無跨執行的查詢共用。三階段實付上限分別 1824、36480、72960。四個 worker，數值執行緒一，稽核解析值與梯度另計。保存所有失敗與不完整軌跡，未觀察到首次反彈的案例標為無法定標，另報數量。
- 正類是原好粒子的 loss 在它第一次地形反彈前，於任一已保存時間嚴格高於自身初值 1e−4，記錄首次觀察時刻。首次反彈之後的 loss 與介入效益不進此標籤。報警時間必須嚴格早於首次已觀察偏離及首次反彈；在報警時間前或同時已偏離的正類算未及時警報，保留在總正類分母。早於偏離的正類警報計提前量。正常負類報警計誤報。
- 比較五種規則。初始速度 (t=0)、第一步當前 loss 增量 (t=.05)、第二步當前 loss 增量 (t=.10) 分別以開發資料選一個高分警報門檻，候選為相鄰分數中點及永遠／從不報警。速度對照取小數點後 14 位，避免把同一設定的浮點誤差當成訊號。最大化平衡準確率，同分先少誤報，再採固定枚舉首項（從不、永遠、遞增中點）。
- 兩個物理預測在固定的反彈前名義時間窗 (tle .30) 對未來已排定的步點預測最高 loss 增量，超過 1e−4 才報警。反彈前水平位移沿初速方向，距離是初速大小乘已知阻尼時鐘的累積位移係數。(t=.05) 時，用第一步 loss 增量反推初始斜率，方向曲率固定為開發資料中從兩步 loss 估得的中位數。(t=.10) 時，直接以兩步 loss 對同一方向求斜率和曲率。兩個規則都只用截至報警時的 loss、初始速度及已知時鐘，無新增梯度、Hessian 或未來事件查詢。評分另外檢查實際反彈是否皆晚於 .30、且早於 .35。預測不使用真實反彈時間。
- 正式報告及時召回率、誤報率、平衡準確率、及時／漏報／誤報計數、提前量與實付至各步的查詢。各動能層分開列，特別標出同一速度下是否有正負混合。每階段的獨立樣本按種子數報，六個動能共用種子。事先成功篩選為至少一個物理規則在正式資料有及時召回 ≥85%、誤報 ≤10%、中位提前 ≥.05，且平衡準確率比最佳單輸入對照高至少 .05。差值另用固定種子 2280 的 2000 次種子群組 bootstrap 給描述性 95% 區間，依事先固定的正式各物理規則對照順序，比較同時間的 loss 單輸入及初始速度。正式結果不調門檻、曲率或觀察窗。
