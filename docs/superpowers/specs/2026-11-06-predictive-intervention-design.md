# 有限預演後介入：已授權設計

使用者已同意上一則提出的預演策略，直接實作及驗證，不再要求重複批准。沿用 brainstorming 設計流程與 codebase-memory 的現有介面查閱。本資料夾沒有 Git；未找到 writing-plans 技能，故在此記錄具體執行計畫。

## 固定設計

- 沿用 StrategicConfig 的純重力、單位質量、地形與孤立二體碰撞。舊模組與舊輸出不改寫。
- 停滯條件不變：視窗 1，連續兩次，進展門檻 1e-4、水平動能 .002、活動 .05。停滯只允許規劃，不直接發球。
- 每次規劃先預演「繼續運動」，再測同一個隨機單位方向與其反方向；供能由低至高為 .10、.20、.30，最多六個方案。每個分支固定預演時間 8，不含新介入。供能超過剩餘預算或不可行的方案略過。
- 各分支均包含歷史最佳值，只評原目標在共同 h=.05 網格上的最佳 loss。歸一化改善為 (baseline_best-candidate_best)/(1+abs(history_best))，必須嚴格大於 1e-4。先選最低可行且通過的供能層，再選該層改善最大者；不可用未完成分支評分。
- 保留短暫上坡；不使用已知極小值、井分界或未來實際執行結果決策。預演值不能當作真實軌跡的最佳解。
- 每次規劃最多 10,000 次 oracle 查詢，整條軌跡最多 18,000 次規劃查詢、兩次規劃決策。所有成功、失敗及取消的預演都使用同一個已計費 oracle。局部規劃額度不足則整次拒絕，保留已花查詢、原物理狀態與供能。
- 真實執行總查詢上限 24,000，規劃前保留至少 6*N*remaining_steps+100 次給後續運動；仍可能因事件成本提前停止，據實報告。
- 真正介入最多兩次、正供能上限 .40；位能零點 z=0。輔助球不刪除。首次衝量控制記錄實際外部做功與動量；不把虛擬球的 .10/.20/.30 冒充控制組實際供能。
- 拒絕規劃後至少等 8 個時間單位再考慮；再次拒絕延長至 16。真正介入後至少觀察完整 8 個時間單位，若沒有超過門檻的實際進展，之後冷卻加倍。不因結果不好倒帶或移除小球。
- 所有介入組在剩餘觀察時間不足 8 時停止新增介入，確保能完整量出一次回饋視窗；不把超過實驗終點的預測當成已實現收益。

## 四組

1. continue：不介入。
2. random_kick：同停滯條件，廉價隨機水平衝量，增加 .20 動能，最多兩次，包含實際回饋與冷卻。
3. predictive_impulse：與發球組採完全相同預演選擇；在預定接觸時刻只施加預測首次碰撞對目標的同一個向量衝量，無輔助球。首次規劃之前可精確配對，後續不假定仍相同。
4. predictive_ball：選定方案後真正插入球，等待接觸並保留後續互動。

首次衝量控制將一個觀察步分成兩段，只在第一段施加原本的阻尼，衝量在真實接觸的同一時間插入，第二段 beta=1。分段各自提交；後段失敗時保留已完成的飛行與衝量。最佳值與目標命中仍只在共同完整觀察網格更新。

## 記帳與輸出

真實系統的來源、阻尼、重力及地形衝量各自記帳；另有目標的來源、二體轉移、阻尼及重力做功。虛擬分支只有查詢與粒子對成本，不加入真實能量帳本。保存每次規劃的分支分數、完成狀態、查詢成本、目標軌跡、選擇理由與首次衝量。

主比較採三種二維情境：低能壞井、好井附近、對稱雙井的精確鞍點（不擾動時 x[0]=v[0]=0 保持對稱）。已知極小值只用於設定與評分。主測試 seed 100..119；預檢使用 seed 90..91，參數在預檢前固定，不依效果調整。

每組固定時間 25、總 oracle 上限 24,000；另在與前輪相同的共同 1,500 次上限評分，所有規劃成本包含其中。查詢達到成本切點時保存當時最後已提交的真實狀態，不能把規劃內找到的低 loss 算成真實改善。若預演在相同預算下沒有收益，須明確報告成本代價。

額外的比較協議核對：由於規劃器會讀取總預算並保留後續運動額度，事後截取 24,000 上限的軌跡不等於一開始告知 1,500 上限。另用完全相同參數、初態與種子，以真實總上限 1,500 再執行四組共 240 條；與原 240 條的「1,500 次前綴」分開報告。這是資源語義的核對，不調整政策或參數。

## 執行與驗證計畫

1. 新增預演規劃器、共用查詢額度與分支隔離。
2. 新增真實執行及完整帳本、精確時間首次衝量控制。
3. 測試：拒絕不改物理狀態／能量、分支最佳值不洩漏、所有成本計費、局部與全局額度、允許先上坡、最低通過供能選擇、方向配對、首碰衝量與目標軌跡一致、已提交事件後失敗、開放系統帳本。
4. 先做小型預檢，完整回歸，再跑主比較 240 條軌跡。
5. 核對成本切點、預測與實際結果、物理殘差、來源雜湊與圖形，保存報告及限制。
