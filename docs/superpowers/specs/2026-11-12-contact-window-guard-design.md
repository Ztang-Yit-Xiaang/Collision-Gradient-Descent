# E37｜第二步的接觸窗預警

E36 固定第二步預測到 .30。正式留下的三例在 .30 仍安全，首次越線發生於約 .317 的首次接觸。本輪用新種子比較固定窗和有條件的精確接觸查詢。

- 固定 E36 雙井、指定好粒子 0、κ=8、起始高度 .025、初始總動能 .6、六動能、重力 .5、步長 .05、阻尼和彈性地形。預檢 2610、正式 2620–2699，各種子六動能，6／480 初態。原第一步、第二步及反彈警報門檻保持 1e−4，主窗到 1.00、較長窗到 2.00。比較同一初態，不按後續結果篩選。
- 新規則只在原第一步未警報、第二步尚未越線、且第二步固定窗最大預測上升落在閉區間 [0.8e−4, 1e−4] 時加查。此保守範圍於運行前固定，涵蓋接觸比 .30 晚約一小段飛行時間時可能增加的 loss，沒有用本批調整。用 .10 狀態付一次精確方向多項式查詢，將多項式重用於每個阻尼後飛行步、配合重力定位最早接觸，最遠搜尋至 .40。只有預測接觸 loss 嚴格超過門檻才於 .10 轉移，找不到接觸則保留、單列。原第二步已有警報時直接照舊。兩政策後續均從各自實際狀態執行相同反彈長窗預警。
- 所有分支使用 E27 水平質心轉移，位置、垂直速度、總動能與線動量保持，角動量變化另記。無二體碰撞、額外供能。新轉移與原政策從同一 .10 狀態比較，反彈分岔共用其各自的反射後狀態。已越線時診斷性強制轉移另報，不混入主預防政策。預檢跑不中斷保留對照。每分支累計至多 960 查詢、40 步，生成 4 次／初態。預檢及正式實付上限 28824／1845120 次，四 worker、單數值執行緒。解析核對另計。新增接觸查詢即使未觸發轉移也實付一次，與後續反彈重算成本分列。
- 主要報原政策首次在接觸越線的數量及新政策能避免到自身首次接觸和到 1.00 的數量。另報至 1.00／2.00 曾偏離、額外轉移及不必要轉移，後者以該時點一路保留也安全及原 E36 已能保護分列。已偏離案例報首次恢復、再次越線、最終在門檻內。預定主篩選為原規則至少三個首次接觸越線、至少防止其中 75% 至 1.00、至 1.00 無新增偏離，新增轉移不必要至多 10%。保存找不到接觸、失敗、不完整與成本，不以正式結果改門檻。僅限同一合成雙井與已知好粒子。
