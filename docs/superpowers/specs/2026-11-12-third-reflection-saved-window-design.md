# E44｜第三次反彈的保存點預測

用 E43 封存的四個只在第四次精確接觸越線的案例診斷時序、loss 及反彈前後方向導數。此為只讀衍生，無查詢或新軌跡。

正式使用 2920–2999、工程 2910，各六種初始動能。共用 E40 軌跡至第三次反彈，沿用 E43 重力、阻尼、受限轉移與門檻。原規則檢查到下一次接觸（含接觸值）。新版先查同段路徑的保存點；若已預測某一保存點越線即可報警。否則用下一次接觸的梯度算自然反射，再付一個方向路徑查詢以預測接觸後第一個保存點。兩次查詢及第一段共三次。接觸值不直接觸發新版轉移。若接觸後第一個保存點超過 5.00 則停在 5.00。若同一子步另有接觸，記預測未完成，不因該未知值轉移。已有保存點或精確接觸越線者兩政策都略過查詢、保留動量。任何一規則要求轉移時從共同第三次反彈後狀態跑一次受限分支，重用於需要它的政策，全部追到 5.00。

主指標為保存點曾偏離，另報含精確接觸、轉移多／少、雙向新增與防止、提前、最終門檻、歷史越線後恢復及再越線。保存點觀察相對好粒子原初態 loss 增加超過 1e−4。預先篩選要求原規則相對保留至少防止三個保存點越線，新版保住全數、不新增保存點越線、且至少少一次轉移。接觸口徑作為單列代價。記預測和續跑的實付與單政策淨差。工程與正式成本上限沿用 E43，第三次反彈每初態最多三次查詢、最多一次 4,096 查詢續跑。無新調參、外力供能或二體碰撞。依舊核對轉移總動能、總線動量與好粒子動能上限。
