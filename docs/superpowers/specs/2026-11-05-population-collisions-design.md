# 多粒子碰撞：已同意設計與本輪實作範圍

使用者已同意依前一則設計試作。本輪不重複詢問批准，保留原有單粒子方法，新增獨立的多粒子執行器與可重現實驗。此資料夾不是 Git repository，不建立額外提交或改動版本控制設定。

## 研究問題

在相同粒子數、初始位置／速度、重力、阻尼時刻與評估預算下，真正接觸時的守恆雙體碰撞，是否優於互不作用的獨立粒子？初始能量不因開啟碰撞而增加。

質量為 1。每個狀態 `(x,z,v,vz)` 的地形中心約束仍為 `z >= ell*f(x)`；兩粒子之間另有 `||q_i-q_j|| >= rho` 的硬核接觸距離。rho 是此理想模型的相互作用距離，不宣稱已處理有限實體球與曲面之間的偏移幾何。

空中重力相同，因此在兩個離散阻尼時刻之間，相對位置為 `r(t)=r0+t*u`，能解析求出兩粒子首次接觸。入射條件是 `u dot n<0`。接觸時沿中心連線作標準等質量彈性衝量；碰撞位置不變，因此粒子對的總動量、動能與重力位能在該瞬間均守恆。

## 排程與邊界

全體共用一個時鐘。在每個觀察大步開始，所有粒子只施加一次既有的速度阻尼。搜尋各粒子的地形接觸與各粒子對的接觸，推進全體至最早事件，處理後重新搜尋。對不共享粒子的同時事件可一起處理；共享粒子的多點接觸明確停止。孤立雙體碰撞若會把貼面粒子推入地形，也必須停止，不能靠位置修補冒充正確的多接觸解。

本輪的群體排程器支援自由飛行與孤立彈性衝量；需要持續貼面支撐力或多點接觸時回報未支援。單粒子 `GravityContact` 的持續接觸實作維持原狀。這個邊界與前一則同意的分階段驗證一致；不能把此版本宣稱為完整的受約束群體力學求解器。

失敗的大步不提交，已花費的值／梯度／解析路徑／粒子對檢查仍計數。失敗不能用其最後最佳值充當成功，成對比較需保留所有初始種子的完成與失敗數。

## 記錄與判準

- 全系統機械能，阻尼能量，牆面與粒子間衝量誤差。
- 全系統動量變化，分別扣除重力、阻尼及牆面反作用衝量；不要求受外力的粒子系統全程動量不變。
- 雙體事件前後動量與動能誤差，實際碰撞次數、接觸距離與入射速度。
- 固定觀察網格上的最佳 loss 與低井目標到達時間；避免碰撞較多的組別因額外事件取樣而得到評分優勢。
- 對可解析的傾斜雙井，沿每段自由飛行精確記錄首次穿越已知分界線的時間，與到達低 loss 的時間分開。
- 相同的總 oracle 呼叫上限（值、梯度、解析路徑各一次均記一個呼叫）與各類上限；這是明確的評估記帳規則，不等於三類查詢實際耗時相同。另列粒子對預測檢查與實際耗時。

另作同成本記帳視角：從完整軌跡採取 `3*N*steps` 次總 oracle 呼叫內的最後完整觀察點（預設 6,000 次），以設定決定上限，不按觀察到的 loss 選擇。這是獨立的事後成本切齊分析，不修改動力學、不插值評分、不重跑或調參。固定運動時間的原結果也保留。

## 實作及驗證順序

1. `population.py`：解析雙體接觸、共同事件時鐘、不可變群體狀態、成本與守恆記錄。
2. `tests/test_population.py`：正面與斜向碰撞、掠碰、不漏中途接觸、事件次序、共享接觸停止、對照與守恆、預算回滾。
3. `population_experiment.py`：受控空中能量重分配、已知雙井障壁、四粒子成對比較；半徑／接觸距離在跑前固定。
4. 先做小型預檢，再固定參數跑 20 個種子。核對全部成對初始能量與預算，保留不利結果。
5. 最後做維度提高時的自由相遇頻率診斷，先確認有無碰撞，再考慮高維優化或 NanoGPT。

## 測試規模

主比較先用二維參數地形（加高度後為三維）：二次函數、傾斜雙井與縮放 Rosenbrock；4 粒子，接觸距離 0.12／0.24，20 種子。無碰撞基線的運動不依賴 rho，因此每個種子只執行一次，再與兩個 rho 成對比較；合計 180 條軌跡、120 組成對比較。共用基線不視為額外獨立樣本。初態為同一套拒絕重疊的固定隨機分布，不按結果製造相撞；受控雙粒子案例則另標為機制驗證，不混入一般效果統計。

程式不加入重新加熱、梯度不利方向觸發、按 loss 動態增大接觸距離或未定義的能量來源。
