# E32｜新種子的首次反彈預警與動量轉移

E31 的十例來自已知後續偏離的狀態。E32 以新種子包含所有符合條件的首次反彈，量化原規則的誤報、漏報與配對效果。

- 固定 E28／E31 旋轉二維雙井、橫向曲率 8、初始相對 loss 分數 300、好粒子 0 起始高度 .025、總動能 .6、線動量 0、重力 .5、步長 .05、阻尼與彈性地形反射。每個種子各用六個起始好粒子水平動能 0.00001、0.00008、0.00015、0.00025、0.0004、0.001。沒有反彈前介入。符合機制比較的案例要求好粒子第一次反彈是第七步的首個單一地形事件，且反彈前六步有效。涵蓋所有此條件的初始狀態，另外留存早到／晚到、其他首事件、求解失敗與不可用預測。採同一地形時間窗，沒有全地形外推。
- 重算 E31 的精確接觸、彈性反射與單次方向路徑預警，規則與門檻固定。從起點到接觸含既有觀察與實算接觸 loss，任一次嚴格高於初始 loss 1e−4 即為已偏離，單獨計恢復。未偏離者用一次付費路徑預測下一保存點 .35，預測增量嚴格超過門檻即報警。如果同一剩餘步內另有接觸令預測無效，列為不可用，政策保留。E28 的 .10 分類只作衍生分組，另報先前未警報者，並不決定入組。
- 所有符合條件者從同一反射後狀態各跑保留與轉移，沿用 E31 質心座標水平分配。兩分支同樣繼承實付前綴、共用接觸與預測查詢，完成剩餘步時不再次施加阻尼，接回原時鐘並各付四次重驗。到步數 20（時間 1.00）或 480 次查詢停止。無二體碰撞、外部供能或後續介入；總能量、三維線動量、角動量變化和逐粒子衝量分開稽核。預檢另跑完整未分岔保留對照，檢查事件、剩餘步及後段。
- 工程預檢新種子 2310、六動能，主比較新種子 2320–2359、240 個初態，至多 240 段前綴、240 段接觸重算、480 段續跑。每個初態初始值四次實算並計費，另四次生成參考。預檢與正式實付上限分別為 8664 與 231360 次，四 worker、單數值執行緒，解析稽核另計。前綴與介入比較共用不重算，衍生政策不另計執行。沒有調參。
- 主要預警評分分母為接觸時尚未曾偏離、有完整保留分支者。用保留分支在 .35 是否首次越線為正負，報真警報、誤報、漏報及無法預測，亦以截至 1.00 是否首次偏離作較長窗的次指標。對警報、未警報與已偏離均報配對：到 .35、到 1.00 曾偏離、峰值與 1.00 loss、已偏離的首次恢復與最終在門檻內。報只在警報時轉移的完整衍生政策，以及另加入對已偏離做診斷性轉移的結果。預定描述性近程篩選為正類至少 5、誤報率及漏報率至多 10%、至少 90% 真警報的配對可防止到 .35 偏離，且沒有警報轉移獨有近程偏離。長窗結果分開解讀，無模型或高維效益宣稱。
