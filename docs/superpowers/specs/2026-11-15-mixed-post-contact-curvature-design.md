# E49｜新種子的混合案例配對

承接 E48 的全陽性壓力測試。固定預測規則、雙井地形、四顆單位質量粒子、時鐘與阻尼、受限轉移及 \(10^{-4}\) 門檻。由 \(t=1.54\) 的同一初態付費預測 E47 與 E48，沿用自然反射和 \(t=5.00\) 停止時間。每個初態都新跑保留分支作為判準。任一規則轉移時，從原決策狀態新跑一次受限轉移，兩規則同選的分支共用軌跡。每政策查詢分別計入設定、該政策實付預測和所選續跑；實驗實付則每條分支只算一次。

固定工程種子 3180、主批 3200–3223。每個種子產生以下七種初態，兩個參數各用以種子和案例編號固定的 PCG64 均勻取樣。比值指首次接觸的 loss 增量除以門檻。地形旋轉和探索粒子速度沿用 E46 生成方式。

| 初態條件 | 接觸時間 | 接觸比值 |
|---|---|---|
| 低能量安全對照 | 1.562–1.567 | 0.00002–0.00020 |
| 較早接觸、低比值 | 1.602–1.612 | 0.005–0.30 |
| 較早接觸、中比值 | 1.602–1.612 | 0.30–0.80 |
| 較早接觸、高比值 | 1.602–1.612 | 0.80–1.05 |
| 較晚接觸、低比值 | 1.633–1.647 | 0.005–0.38 |
| 較晚接觸、中比值 | 1.633–1.647 | 0.38–0.65 |
| 較晚接觸、高比值 | 1.633–1.647 | 0.65–1.05 |

事前固定全部七組與所有種子，工程只驗證運行、能量帳與資料完整，沒有門檻調整或依結果篩選。按保留分支的完整保存軌跡定義一路安全與曾越線，與預測輸出獨立。報告配對下新增防止、失去原保護、提早／新增偏離、全程安全分支的不必要轉移和首次越線時間。另報含接觸、恢復／再越線、終點 loss、保存點歷史最低 loss、兩政策預測與總查詢，按保留分支結果分開。機制篩選要求主批有兩類案例，且延伸能新增預防、保住原先的預防，沒有額外的不必要轉移。照實報不符合的結果。構造的分層混合比例用於機制檢查。

每初態最多四次設定、每規則三次預測、兩條續跑各至多 4,096 次查詢，工程總上限 57,414，主批 1,377,936。停於 5.00 或查詢耗盡、求解失敗。查詢或求解失敗要留檔並停止該批。轉移過程外部供能上限為零。轉移核對總動能、線動量和受限水平動能，逐段記錄角動量變化。續跑核對重力做功、牆面衝量、阻尼耗散和數值殘差。以保留分支的精確事件核對預測的適用區間，分開記錄時間窗以外或被另一接觸截斷的案例。
