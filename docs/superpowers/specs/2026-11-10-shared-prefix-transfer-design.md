# E27｜共同觀察軌跡後的動量轉移

E26 的早期衝量只有事後排序，且可區分保留與轉移的獨立種子很少。E27 先在開發集找兩種動作都可能勝出的條件，再把同一段觀察結束後的狀態實際分岔。問題是地形衝量能否在同查詢預算下協助當下介入。

- 固定 E26 的二維旋轉雙井、κ=8、起始相對 loss 分數 300、最佳點高度 .025、總高度 3.2、初始總動能 .6 與線動量 0、重力 .5、步長 .05、同一阻尼與彈性地形反射。四顆獨立點粒子。觀察步數固定 10，時刻 .5。共用該段狀態、值和事件。觀察終點按當下已付費 loss 的首次 argmin 選擇粒子。特徵使用該粒子的前綴地形水平淨衝量模長、當下 loss 差距分數、當下相對質心水平動能。最後一項只作機制排序診斷。
- 一律保留從同一狀態繼續。一律轉移先將水平速度移到共同質心座標，套用 E24 四粒子轉移映射，再加回共同速度。選中者的質心相對水平速度歸零，其他三顆重新分配水平動能。所有位置與垂直速度維持原樣，總動能、總能量、三維線動量在映射中保持。角動量變化及逐粒子衝量另記。這是排定時刻的一次人為介入，沒有二體碰撞或運行中補能。續跑沿用已走的阻尼時鐘和查詢計數，兩分支皆實付重驗四個值。
- 預檢種子 2090、起始粒子 0 水平動能 .04、兩種情境。跑兩段前綴、四段續跑與兩條不分岔保留供工程等價檢查，比較共同已提交步驟。開發種子 2100–2111，僅全壞井，將粒子 0 初始動能固定為 .001、.04、.12 三設定，各維持相同總動能和線動量。36 段前綴、72 段續跑。按僅保留及僅轉移成功的較小計數最大化，再按兩者總和最大化，最後取較小動能，鎖定一設定。每個方向至少五個獨立種子是可辨識門檻。即使開發不足，仍完成預定的正式機制檢查並按不足解讀。
- 正式 2120–2139，鎖定的動能設定，含好點及全壞井各 20 個狀態，共 40 段前綴和 80 段續跑。開發與正式每條完整政策最多 6000 次查詢（含前綴和四次重驗）與 500 步。預檢最多 1200 次與 80 步。每狀態初始值共用實算四次，另有四次生成／評分參考。開發與正式實付含生成上限 432144／480160 次，預檢（含兩條不分岔對照）上限 7208 次。共四 worker，數值執行緒各一。固定步數／查詢停止，稽核查詢另列。前綴失敗時保留原始成本，無可比較的續跑，不重跑替換。
- 在選定的開發設定中，各自用前綴衝量、當下 loss 差距擬合一條單特徵規則。候選為兩個常數動作與相鄰觀測分數中點的兩個方向。優先最大化壞井最終達標，其次減少轉移次數，最後採固定枚舉順序（常數保留、常數轉移、由小到大的中點，每個先高分轉移）。壞井機制排序方向只用開發雙向結果決定（AUC 小於 .5 則反向，其餘向上），兩階段每種偏好至少五個獨立種子才解讀比較。AUC 平手給 .5。正式衍生規則結果只讀同前綴上實際完成的兩分支，無第三次執行。
- 主指標按同查詢預算，並另報共同最短已保存時間。好粒子途中曾明顯偏離初始解的次數（上升嚴格超過 1e−4）分別報共同前綴、整段和僅在分岔後首次發生，原好粒子最後達標另報。壞井最終與歷史達標分開，記保留／轉移的配對切換。候選衝量規則要在開發與正式均達辨識門檻、正式壞井達標數至少比兩個常數及 loss 規則各多 2，且好粒子整段偏離與最後達標各不比一律轉移差超過 2，才通過描述性篩選。前綴已發生的偏離不能由後續介入消除。保留全部失敗、查詢及物理帳，不依正式結果改門檻。
