# E37｜第二步的接觸窗預警

## 設計

E36 的第二步固定預測到 (t=0.30)，最後三個早期漏報在第一次精確接觸時才越線。E37 用 80 個新種子、每個六種初始動能，配對比較固定窗和有條件的精確接觸查詢。好粒子、雙井曲率、初始高度、重力、阻尼及偏離門檻沿用 E36。

第一步沒警報、第二步也還未越線時，若對 .30 的外推落在門檻的 80%–100%，就於 (t=0.10) 付一次方向路徑查詢。沿同一已付多項式和阻尼時鐘定位未轉移分支的第一次接觸，預測該點的 loss。只有接觸預測嚴格越線才在 .10 轉移。若原第二步已警報，照原規則轉移。之後兩政策都在各自真正走出的首反彈上重新判斷。門檻及加查區間在正式前固定。[E37 協議](superpowers/specs/2026-11-12-contact-window-guard-design.md)

## 正式配對

80 個新種子（2620–2699）各測六種初始動能，共 480 個配對初態。偏離指指定好粒子在保存觀察點或首次精確接觸的 loss 比自身初始 loss 高出超過 \(10^{-4}\)。恢復指偏離後回到門檻內，歷史偏離仍計入。

| 指標 | E36 固定窗 | E37 接觸窗 |
|---|---:|---:|
| 首次在接觸時越線 | 3/480 | 0/480 |
| 好粒子途中曾明顯偏離初始解的次數，至 \(t=1.00\) | 3/480 | 0/480 |
| 好粒子途中曾明顯偏離初始解的次數，至 \(t=2.00\) | 22/480 | 19/480 |
| \(t=2.00\) 當下在門檻內 | 477/480 | 480/480 |
| 第二步轉移 | 21 | 24 |
| 全部轉移 | 357 | 360 |
| 政策預測查詢 | 1,187 | 1,212 |

16 個初態進入加查區間，每個付一次，全部找到接觸。13 次查詢後保留原動量，3 次在 \(t=0.10\) 轉移。這三次恰好配對防止原規則在約 \(t=0.317\) 的三個首次接觸越線，保護維持到 \(t=2.00\)。三例均屬初始動能 0.00015，舊規則的接觸 loss 增量為 \(1.046–1.078\times 10^{-4}\)，轉移後自身首次接觸降至 \(0.081–0.175\times 10^{-4}\)。至兩個時窗皆無新增偏離。新增轉移中，從第二步起一路保留也安全為 0/3，沿用 E36 後續規則就能保護也為 0/3。

政策預測成本增加 25 次，其中 16 次為第二步加查，9 次為改變軌跡後在各自首反彈執行的原有長窗預測。三個新保護案例在 E36 接觸時已越線，當時略過了長窗預警。其餘 19 次在 \(t=1.00\) 之後才出現的偏離兩政策共有。結果通過預定篩選。[正式指標](../output/collision_contact_window_guard/results.json) · [三個首次接觸越線的配對](../output/collision_contact_window_guard/first_crossings_at_contact.json)

## 接觸時已偏離的配對恢復

E36 在首次接觸有 3 例已偏離，E37 為 0 例。兩政策第一步與第二步當下均無已偏離案例。對 E36 的三例從同一剛反彈完的狀態分別保留及強制轉移。強制轉移是恢復診斷，獨立於預防政策計價。

| 三個接觸時已偏離案例 | 保留 | 反彈後立刻轉移 |
|---|---:|---:|
| 至 \(t=1.00\) 曾恢復 | 0/3 | 3/3 |
| 至 \(t=2.00\) 曾恢復 | 2/3 | 3/3 |
| 恢復後至 \(t=2.00\) 再越線 | 2/2 | 0/3 |
| \(t=2.00\) 當下在門檻內 | 0/3 | 3/3 |

強制轉移後三例在 \(t=0.40\) 的保存觀察已回到門檻內。保留組兩例在 \(t=1.15\) 首次恢復，分別於 \(t=1.90\)、\(1.95\) 再越線。[逐例恢復與 loss](../output/collision_contact_window_guard/policy_recovery_cases.json)

## 執行與範圍
